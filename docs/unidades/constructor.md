# Constructor

<img src="../../assets/img/units/constructor.png" alt="Constructor" width="180" align="right">

_Unidad de construcción · Facción Terránea_

`Clase Ligera` · `Cupo civil` · `Gobierno nivel 1`

> Unidad civil destinada a construir edificios de la civilización. Gracias a ella es posible la producción de unidades civiles y/o militares. Necesario para el crecimiento del ejército.
