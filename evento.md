# Próximo evento

Para anunciar un evento, añade debajo una línea con la fecha y hora (hora de España, formato DD/MM/AAAA hh:mm:ss), por ejemplo la palabra «Fecha:» seguida de la fecha.
La web lo lee sola cada pocos minutos; no hace falta desplegar nada. El banner desaparece una hora después de la hora fijada.

Mientras no haya ninguna fecha aquí, no se muestra ningún banner.
